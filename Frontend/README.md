# Welfare Massage Centre - Frontend Website

Professional massage therapy centre website built with React + Vite, fully optimized for SEO and accessibility.

## 🌟 Features

- **Modern React Application**: Built with React 18 and Vite for optimal performance
- **Comprehensive SEO Optimization**: Fully optimized for search engines and local SEO
- **Accessibility Compliant**: WCAG 2.1 compliant with proper ARIA labels and semantic HTML
- **Mobile Responsive**: Fully responsive design for all devices
- **Performance Optimized**: Fast loading times with lazy loading and optimized assets
- **Schema.org Structured Data**: Rich snippets for better search engine visibility

## 🚀 Quick Start

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
